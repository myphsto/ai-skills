## Linux sysadmin (33 skills)

Debian/Ubuntu and RHEL-family server operations. Each skill is standalone
with its own references and evals; `linux-sysadmin` is the routing hub.
Thirty-two skills are adapted from the MIT-licensed
[peterbamuhigire/linux-skills](https://github.com/peterbamuhigire/linux-skills)
project (credit kept in each skill's `metadata.source`); `linux-zfs` is
original.

|-------|-------------|
| linux-sysadmin | Routing hub: picks the right specialist skill |
| linux-server-provisioning | Interactive first-boot setup of a fresh server |
