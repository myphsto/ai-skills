# Research

## Overview

Every factual claim requires evidence. Evidence quality varies — knowing the difference between strong and weak sources determines whether your research is trustworthy.

## Core Rules

**No claim without a citation.** For every factual assertion:
1. Identify the source
2. Assess its tier (see hierarchy below)
3. Include a direct link
4. Note the tier if it matters to credibility

**No exceptions.** Pressure, deadlines, and authority figures do not override this rule. An uncited claim is an unsubstantiated claim.

**No assumptions or inferences.** Do not speculate, extrapolate, or fill gaps with reasoning alone. If a claim cannot be backed by evidence, label it explicitly as unsubstantiated: "Unsubstantiated: [claim]." Never present an assumption as fact.

**Format:** State the claim, then cite inline: `([Source Name, Tier N](https://example.com/source))`

## Evidence Quality Hierarchy

| Tier | Quality | Examples |
|------|---------|---------|
| **1** | Gold standard | Peer-reviewed journals, meta-analyses, systematic reviews (PubMed, Nature, Science, IEEE) |
| **2** | Strong | Government/institutional reports, official documentation, Wikipedia (enforces cited references — may lag on breaking topics) |
| **3** | Moderate | Reputable investigative journalism (Reuters, AP, NYT), industry analyst reports (Gartner, IDC), established case studies from known organizations |
| **4** | Weak | General blog posts, personal websites, unverified tutorials, opinion pieces |
| **5** | Unreliable | Tabloids, anonymous sources, social media posts, undated or unattributed content |

## Rules

- **Prefer higher tiers.** If a Tier 1 source exists, don't cite a Tier 4.
- **Exhaust higher tiers before citing Tier 4–5.** If you find only a weak source, actively search for a Tier 1–3 corroborating source first. Only cite Tier 4–5 when no higher-tier source can be found after a genuine search attempt.
- **Acknowledge weak sources.** When citing Tier 4–5, state explicitly: "No higher-tier source found. This comes from [source type] (Tier N) — treat with appropriate skepticism."
- **Don't fabricate links.** If you cannot find a verifiable source, say "I don't have a verified source for this" rather than guessing.
- **Velocity matters.** Not all topics age the same way. For static topics (math, fundamental physics), old sources are fine. For fast-moving topics (web frameworks, AI/ML, dev tools), sources older than ~12 months may be stale — seek current corroboration. For breaking topics (news, active incidents, new launches), sources older than ~30 days are stale. A source's age never changes its tier — a 10-year-old Nature paper is still Tier 1, just stale for a fast-moving topic.
- **Check primary sources.** When a secondary source cites a study, find and link the original.
- **No source summary tables.** Don't produce a summary table of sources at the end. Citations are already inline — repeating them is noise.

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| Citing a blog that summarizes a study | Find and link the actual study |
| Stating a fact with no citation | Add source or flag as unverified |
| Treating all web pages equally | Apply the tier system |
| Using a stale source on a fast-moving topic | Note the date, seek recent corroboration |
| Linking to a paywall without flagging it | Note: "paywalled — abstract available at [url]" |
